How it works

1

Copy

Copy anything with ⌘C as you normally do.

2

Double-press

Press ⌘C again. A floating panel appears near your cursor.

3

Pick an action

Choose from context-aware suggestions. The result lands in your clipboard.

Built for this

On-device AI

Summarize, translate, rewrite, and fix grammar using the local LFM 2.5 model. No API keys. No cloud calls.

Source-aware

Detects if you copied from email, chat, browser, IDE, or terminal — and ranks actions accordingly.

Instant transforms

Format JSON, decode Base64, strip ANSI, convert HTML to Markdown. No network, no waiting.

Content extraction

Strips ads, navigation, and boilerplate from web pages before converting. Clean Markdown every time.

Extensible

Create custom SKILL.md files with your own prompt actions or URL templates. Override any built-in.

Native & lightweight

SwiftUI menu bar app. Under 15 MB. No Electron, no web views, no background daemon.

Your clipboard stays yours

CopyCopy runs entirely on your Mac. AI processing happens on-device using Apple's MLX framework. Nothing is sent to any server, ever.

No telemetry No clipboard history No network calls Open source
